# ShitDevScripts Versions

Centralized version information for **ShitDevScripts** resources.

This repository contains version information for ShitDevScripts resources, allowing scripts to check for available updates and keep track of their latest releases.

## Available Resources

| Resource | Version Information |
|---|---|
| ShitDevScripts-Banking | Available |
| ShitDevScripts-Billing | Available |
| ShitDevScripts-Bossmenu | Available |
| ShitDevScripts-Database | Available |
| ShitDevScripts-Scoreboard | Available |

## Purpose

The repository is designed to provide a central location for version information.

- Check the latest available script versions.
- Detect when updates are available.
- Keep version information separate from individual resources.
- Make update checking easier across ShitDevScripts resources.

## Updates

Version information is updated whenever a new release or update becomes available.

Make sure your version checker points to this repository to receive the latest version information.
